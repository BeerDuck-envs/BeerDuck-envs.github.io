# 潘佳阳的学术主页

本项目基于 [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) 模板构建，用于展示个人简介、研究成果、科研项目与竞赛荣誉。

## 发布到 GitHub Pages

1. 将本目录上传至名为 `BeerDuck-envs.github.io` 的公开仓库。
2. `_config.yml` 已配置为 `BeerDuck-envs/BeerDuck-envs.github.io`。
3. 在仓库 **Settings → Pages** 中选择从 `main` 分支部署。
4. 发布地址为 `https://BeerDuck-envs.github.io/`。

主页内容在 `_pages/about.md`，个人资料在 `_config.yml`，头像为 `images/profile.jpg`，简历为 `assets/resume.pdf`。

## 本地预览（可选）

模板使用 Jekyll。安装 Ruby 与 Bundler 后，执行 `bundle install` 和 `bundle exec jekyll serve`，然后访问 `http://127.0.0.1:4000`。
